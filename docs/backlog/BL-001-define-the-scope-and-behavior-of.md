# BL-001 — Define the scope and behavior of a personal pi todo tracker

- Outcome: Decide whether the need is branch-local progress, durable agent memory, or project task management, then define a minimal tracker's mutation/status, persistence, model reminders, completion authority, and plan/subagent boundaries.
- Next action: Clarify the intended use case with the user and compare a minimal design using the completed research.
- Done when: An explicitly accepted design and its exclusions are recorded.
