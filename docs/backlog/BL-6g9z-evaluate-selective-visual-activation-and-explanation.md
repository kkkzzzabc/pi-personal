# BL-6g9z — Evaluate selective visual activation and explanation quality with a real model

- Outcome: Check whether a real model selects visuals only when useful and produces accurate, legible editorial explanations across structure, mechanism, comparison, and data tasks. Offline faux tests establish resource delivery, not this behavior.
- Next action: Propose a small prompt set, model and usage bounds, evaluation rubric, and evidence policy; obtain approval for additional live provider calls before running.
- Done when: A bounded evaluation records activation decisions, content and screenshot checks, failures, and environment/model limitations.
- Trigger: After initial use reveals routing or explanation-quality uncertainty, or the user requests a real-model evaluation.
